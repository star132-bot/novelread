# MKBook 写作与打包指南

这份指南讲怎么写一本书交给 MKread：先写 `.mktxt` 稿子，再用打包工具生成 `.mkbook`，导入 App 或上传到云端书库。完整规则见 [mkbook-v1.md](mkbook-v1.md)。

| | `.mktxt`（写作稿） | `.mkbook`（发布包） |
|---|---|---|
| 是什么 | 一个纯文本文件，用任何编辑器写 | ZIP 包，里面是正文、封面、插图和清单 |
| 谁来写 | 作者 / 整理者手写 | 打包工具自动生成，**不要手工改** |
| 用来 | 编辑、改稿 | 导入 App、上传云端 |

---

## 一、准备文件夹

```text
夜行者/
├── 夜行者.mktxt                  稿子（UTF-8 编码）
├── 夜行者.pronunciation.json     读音表（可选，文件名必须和稿子同名）
└── img/
    ├── cover.jpg                 封面
    ├── house.jpg                 插图
    └── night.png
```

图片支持 **JPEG / PNG / WebP**，每张不超过 **10 MB**，整本书打包后不超过 **200 MB**。图片文件名里不要有空格。

可以直接照着仓库里的示例改：[`examples/插图示例/`](examples/插图示例/)（带封面和两张插图）、[`examples/夜行者.mktxt`](examples/夜行者.mktxt)（分卷和读音表）。

## 二、写 `.mktxt`

### 1. 开头的元数据

文件最开头，两行 `---` 之间，每行一个 `键: 值`：

```text
---
id: yexing-zhe
title: 夜行者
author: 某某
description: 一句话简介
tags: 悬疑, 都市
status: ongoing
cover: img/cover.jpg
---
```

| 键 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 书的永久编号：小写字母、数字、`.` `_` `-`，2–64 位，以字母或数字开头。**发布后不能改**，App 和云端靠它认出"同一本书的新版本"。建议用拼音，如 `yexing-zhe` |
| `title` | ✅ | 书名 |
| `author` | | 作者 |
| `description` | | 简介（写在一行里） |
| `tags` | | 标签，用逗号分隔 |
| `status` | | `ongoing`（连载中）或 `completed`（已完结） |
| `cover` | | 封面图片路径，相对于 `.mktxt` 文件 |
| `language` | | 默认 `zh-CN` |

### 2. 卷和章

```text
# 第一卷 起始

## 第1章 夜访 {#c0001}

正文……

## 第2章 旧事 {#c0002}

正文……

# 第二卷 远行

## 第3章 出城 {#c0003}
```

- `# ` 开头是**卷**：后面的章节都属于这一卷，直到下一个 `# `。没有分卷就不写。
- `## ` 开头是**章**：`##` 后面要有一个空格。
- 章标题末尾的 `{#c0001}` 是**章节编号**，可以不写（工具会按顺序生成 `c0001`、`c0002`……）。但书一旦发布过，**建议写上并且永远不改**：读者的阅读进度是按章节编号保存的，改标题、改正文都没关系，编号不变进度就不会丢。
- 标题只写在 `##` 这一行，不要在正文里再写一遍。

### 3. 正文

- **一行就是一段**。段首不用空格缩进（App 会自动排版）。
- 空行会被忽略，可以随意用空行让稿子好看。
- 场景切换写单独一行 `※※※`，朗读时会跳过。
- 数字、单位、英文照常写（`2024年`、`65kg`、`MKread`），朗读时会自动转成中文读法。

### 4. 插图：想放哪里就写在哪里

在正文里**单独一行**写：

```text
![图片说明](img/house.jpg)
```

- 路径相对于 `.mktxt` 文件；方括号里的说明会显示在图片下方，可以留空：`![](img/house.jpg)`。
- **这一行写在哪，图就出现在哪**：
  - 写在章节第一行 → 本章开头
  - 写在章节最后一行 → 本章末尾
  - 写在两段之间 → 两段中间
- 在 App 里每张插图单独占一页（等比缩放到屏幕大小）；朗读时自动跳过。
- 同一张图可以在多处引用，打包时只存一份。
- 这一行前后不能有别的文字，否则会被当作普通文字。

### 5. 完整示例

```text
---
id: yexing-zhe
title: 夜行者
author: 某某
status: ongoing
cover: img/cover.jpg
---

# 第一卷 起始

## 第1章 夜访 {#c0001}

![林默的小屋](img/house.jpg)

夜色渐深，林默推开那扇吱呀作响的木门。
屋里只点着一盏油灯。

※※※

老人抬起头，缓缓说道："你终于来了。"

## 第2章 旧事 {#c0002}

老人从怀里掏出一张泛黄的照片。
……

## 第3章 灯火 {#c0003}

林默点点头，没有说话。
![夜色](img/night.png)
```

这本书的效果：第 1 章第一页是小屋插图，第 3 章最后一页是夜色插图，书架上显示 `cover.jpg`。

## 三、读音表（可选）

人名、地名、多音字读错时，在稿子旁边放一个同名的 `夜行者.pronunciation.json`，打包时会自动带上：

```json
{
  "schemaVersion": 1,
  "overrides": [
    { "source": "单于", "replacement": "缠于", "match": "literal" },
    { "source": "MKread", "replacement": "M K read", "match": "whole-token" }
  ]
}
```

- `source` 是原文，`replacement` 写一个**读起来对**的同音写法。
- `literal`：出现在任何地方都替换；`whole-token`：只替换完整的英文单词（前后不是字母或数字）。

## 四、打包成 `.mkbook`

需要电脑上有 Python 3，不用装任何依赖。在仓库根目录运行：

```bash
python3 tools/mkbook/mkbook.py build 夜行者/夜行者.mktxt -o 夜行者.mkbook
```

成功会显示：`已生成 夜行者.mkbook：《夜行者》 r1，3 章，5230 字，2 张插图，含封面`。

出错会用中文说明原因（例如"找不到插图文件：img/house.jpg"），改好再打包即可。

**已有的 TXT / EPUB 也能直接转：**

```bash
python3 tools/mkbook/mkbook.py build 小说.txt  --id xiao-shuo --cover 封面.jpg -o 小说.mkbook
python3 tools/mkbook/mkbook.py build 小说.epub --id xiao-shuo -o 小说.mkbook
```

- TXT 会自动按"第X章 / 第X回 / 序章 / 楔子 / 番外"切分章节。
- EPUB 自带的封面会自动使用，正文里的图片会按原位置变成插图。
- 也可以用 `--title`、`--author` 覆盖书名和作者。

**检查与查看：**

```bash
python3 tools/mkbook/mkbook.py validate 夜行者.mkbook   # 检查是否合规
python3 tools/mkbook/mkbook.py info 夜行者.mkbook       # 查看书名、目录
```

## 五、更新一本已发布的书

改完稿子后，带上**上一版的 `.mkbook`** 打包：

```bash
python3 tools/mkbook/mkbook.py build 夜行者/夜行者.mktxt --previous 夜行者.mkbook -o 夜行者-r2.mkbook
```

- 版本号（revision）自动 +1；没写 `{#编号}` 的章节会按标题沿用旧编号。
- 会列出新增、删除、修改了哪些章节。
- 导入 App 或上传云端后，旧版会被原地替换，**阅读进度保留**。
- `id` 必须和上一版相同；用 `diff` 可以对比两个版本：`python3 tools/mkbook/mkbook.py diff 旧.mkbook 新.mkbook`。

## 六、放进 App

- **本地导入**：把 `.mkbook` 传到手机，在 MKread 书架点右下角 **＋** 选择文件。
- **云端书库**：登录管理平台 `https://books.mkauth.sbs/admin/` →「书籍 → 上传书籍」，选文件并填写原因。所有已登录的 App 会在下次同步时自动下载（联网时每 6 小时一次，也可以在「云端书库」页手动同步）。

> 带插图的书需要 MKread **0.4.0 或更新版本**。没有插图的书老版本也能导入。

## 七、常见问题

| 问题 | 原因 / 解决 |
|---|---|
| 插图显示成一行文字 | 那一行前后有别的字，或图片路径里有空格。插图必须单独一行 |
| 打包提示"找不到插图文件" | 路径要相对于 `.mktxt` 所在文件夹，注意大小写 |
| 提示"插图不是 JPEG/PNG/WebP" | 文件扩展名改了但格式没变（例如 HEIC 改名成 .jpg），请用图片软件另存为 JPEG |
| 更新后阅读进度丢了 | 章节编号变了。给每章写固定的 `{#编号}`，或打包时加 `--previous` |
| 导入提示"这本书使用了更新的格式" | App 版本太旧，升级到 0.4.0 以上 |
| 同一本书导入后出现两本 | 两次的 `id` 不一样。`id` 发布后不能改 |
| 朗读把某个字读错 | 加读音表（第三节） |
