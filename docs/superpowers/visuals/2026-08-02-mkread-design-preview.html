离线优先 · Android 10+ · TXT / EPUB

MKread 设计预览

小说导入、分页、编辑、情感分析、音色推理和后台播放全部在设备本地完成。首版采用原生 Android、sherpa-onnx 与 ZipVoice-Distill INT8。

总体架构

界面与用户操作

书架 / 文件管理导入、搜索、排序、删除、阅读进度和最近阅读。
阅读 / 编辑自动分页、文字选择与复制、正文编辑、朗读句高亮。
播放器 / 设置音色、速度、情感开关、定时停止、日间与夜间模式。
↓

应用核心

导入与解析编码识别、EPUB 安全解包、章节提取和正文标准化。
分页与位置映射在字符偏移、页面、章节和朗读语句之间稳定定位。
朗读编排断句、情绪选择、语音任务队列、预生成与失败恢复。
音色包管理验证、安装、启用和卸载 .mkvoice 音色包。
↓

设备运行时

sherpa-onnx + ZipVoice中英文 INT8 离线合成，依据情绪选择参考风格。
Media3 播放服务后台播放、锁屏通知、耳机控制和音频焦点。
后台任务小说解析、分页索引、缓存清理和模型完整性检查。
↓

本地数据

Room 数据库书籍、章节、进度、设置、编辑版本和音色元数据。
应用私有文件小说副本、封面、模型、音色参考和分页索引。
有界音频缓存缓存当前与后续语句，按容量和最近使用时间清理。

核心数据流

01导入 TXT / EPUB

系统文件选择器选择文件，不申请宽泛存储权限。
→
安全校验检查格式、大小、编码和 EPUB 压缩路径。
→
复制与标准化写入应用私有目录，原文件保持不变。
→
解析与索引提取章节、封面，并在后台建立索引。

02分页阅读

按需读取章节不把整本大型小说放进界面内存。
→
计算字符区间依据屏幕、字体、字号和行距分页。
→
渲染与选择翻页、复制和当前朗读句高亮。
→
保存进度记录章节与字符偏移，不依赖易失效页码。

03离线情感朗读

上下文断句结合前后句识别旁白、对白和停顿。
→
情绪编排选择中性、愉悦、悲伤、愤怒或紧张。
→
ZipVoice 生成后台提前生成后续 2 至 3 句音频。
→
Media3 播放连续播放、系统控制和句子高亮。

04正文编辑

编辑应用内副本支持撤销、取消与明确保存。
→
保存新版本事务写入，保留短期撤销记录。
→
局部重建缓存只清除受影响章节的分页与语音缓存。
→
恢复字符锚点回到编辑附近，原始文件不被覆盖。

.mkvoice 音色包

manifest.json
格式版本、音色 ID、名称、语言和引擎兼容版本。
references/
中性与可选情绪参考 WAV，以及每段录音的准确文字。
checksums.json
文件哈希、大小限制和完整性验证。
manifest.json 授权字段
内嵌音色来源与授权声明；无声明包不允许安装。

关键回退规则

情感关闭固定使用中性参考风格和用户设置的朗读速度。
情感样本缺失回退到中性风格并微调停顿，不伪造不存在的音色样本。
播放被打断来电或其他应用抢占音频时暂停，之后由用户主动继续。
缓存受限按容量上限清理；语音缓存损坏时可重新生成，不影响正文。
设计确认点：阅读进度始终使用“章节 + 字符偏移”；情感朗读关闭时只使用中性音色；正文编辑只影响应用内副本；所有语音处理保持离线。
