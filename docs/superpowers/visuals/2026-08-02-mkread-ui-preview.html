关键异常处理

小说无法导入

在加入书架前完成格式、大小和编码校验；失败时显示具体原因，且不留下半成品记录。

存储空间不足

显示所需空间和当前可用空间，提供“管理语音缓存”入口，不自动删除小说或音色。

语音生成跟不上播放

暂停在当前句并显示“正在准备语音”，不跳句；用户可切换到流畅模式。

音色包不兼容

原子校验格式版本、引擎、哈希、WAV 参数与授权声明；任一失败即拒绝整个包。

播放被其他应用打断

来电或导航抢占音频时自动暂停；音频焦点恢复后等待用户主动继续。

播放中编辑正文

先停止当前语句；保存后只重建当前章节的分页和语音队列，再回到编辑锚点。

应用被系统结束

保留最后确认的字符位置和播放器状态；再次打开时恢复页面，语音缓存按需重建。

重复导入同一文件

比较内容哈希后让用户选择“打开已有副本”或“另存为一本”，避免静默覆盖编辑内容。

界面原则

离线可见应用不声明网络权限；所有需要模型的功能在安装包与本地音色包中完成。
位置稳定字号、主题或正文变化后，仍通过字符锚点恢复到接近原来的位置。
操作可撤销编辑和删除等高风险操作提供撤销或明确确认，不修改用户原始文件。
状态不遮挡正文朗读高亮、加载提示和播放器保持固定区域，不使页面跳动或覆盖文字。
本节确认点：底部导航采用“书架 / 音色 / 设置”；阅读页默认为专注翻页；情感朗读、推理模式和定时停止位于朗读控制面板；异常不会破坏原小说或静默跳过内容。
